# WSN-Guard 🔐

Machine learning-based Intrusion Detection System (IDS) for Wireless Sensor Networks (WSN), designed to detect malicious activities using efficient preprocessing and lightweight classification techniques.

---

## 🎯 Objective

To build an effective and scalable IDS for WSN that can accurately identify normal and malicious network behavior using machine learning.

---

## ⚙️ Tech Stack

* Python
* Scikit-learn
* TensorFlow
* NumPy, Pandas
* Matplotlib / Seaborn

---

## 🔍 Features

* Data preprocessing and cleaning
* Handling imbalanced data using SMOTE
* Feature selection and dimensionality reduction (PCA)
* Classification using Stochastic Gradient Descent (SGD)
* Performance evaluation (Accuracy, Precision, Recall, F1-score)

## ▶️ How to Run

1. Clone the repository

   ```bash
   git clone https://github.com/MohdJalal1/WSN-Guard.git
   cd WSN-Guard
   ```

2. Install dependencies

   ```bash
   pip install -r requirements.txt
   ```

3. Run the project

   ```bash
   python wsn_ids_sgd.py
   ```
